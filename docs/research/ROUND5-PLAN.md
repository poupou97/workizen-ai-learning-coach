**Priority #1:** raise data accuracy. The long-term strategy `WRONG → WITHHOLD → DONE` is rejected. Every failure class must move to `DETECT → REPAIR candidate → VALIDATE → RESTORE or WITHHOLD`. A repair is never trusted by default. Coverage must begin to recover **without loosening a guard**.

**Falsified in round 4 and binding here:** `OCR_A == OCR_B` does **not** imply `TEXT == TRUE` (two stacks make the same error). Hence the third-signal layer.

**Data versioning (all lanes):** every value carries a disposition — ORIGINAL OBSERVATION · REPAIRED CANDIDATE · VALIDATED REPAIR · TRUSTED · WITHHELD · LEGACY · SUPERSEDED. **Never overwrite a source observation.** Every repair traces source → observation → failure → repair rule → supporting signals → validation → final disposition.
