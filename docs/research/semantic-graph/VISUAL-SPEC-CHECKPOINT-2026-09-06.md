## 3 · VISUAL SPEC — verbatim from the artefact

```json
{ "specVersion": "visual-spec-v1",
  "primary": {
    "family": "sequence",
    "title": "Thực hành: tổng hợp lực (bài 22)",
    "nodes": [
      { "id": "section-1", "label": "1. Dụng cụ thí nghiệm (Hình 22.3)", "badge": "1",
        "status": "stated",
        "provenance": { "blockIds": ["10-sgk-vat-li-10:p89:gold:b03"],
                        "derivationRule": "numbered-section-sequence-v1",
                        "trust": "fixtureFromTrustedCorpus" } },
      … section-2, section-3 …
    ],
    "edges": [
      { "fromId": "section-1", "toId": "section-2", "kind": "sequence",
        "status": "derivedDeterministic",
        "provenance": { "blockIds": ["…:b03", "…:b05"], … } }
    ] } }
```

Read the two `status` values against each other — that is the whole point of the layer:

- the **node** is `stated`: the label is the book's own heading, character for character;
- the **edge** is `derivedDeterministic`: the book prints these adjacently, and the arrow is
  SAM's arrangement of them. **A visual arrow is never source truth**, and the spec says so in
  a field rather than in a comment.
