## Họ hỏng lặp lại, có tên

| dấu vết | ví dụ thật |
|---|---|
| chỉ số dưới → dấu phẩy | «2H₂O ⟶ 4H⁺ + 4e + O₂» → «2H,O 4 H* + 4e + 0,» |
| **dấu «+» → chữ «t»** | «Li⁺» → «**Lit**» · «+e» → «**te**» |
| số mũ biến mất | «x³ + (−3x²y) + 3xy²» → «x + (-3xy) + 3xy» |

| chỉ số log biến mất | «log₃5 + 2log₉25» → «log, 5 + 210g, 25» |
