Pre-flight (read-only, before ANY input — repeated before every input burst):
```
d() { /Users/alexnguyen/Library/Android/sdk/platform-tools/adb -s 192.168.1.3:5555 "$@"; }
d shell dumpsys window | grep mCurrentFocus      # must show ai.workizen.learningcoach (or launcher before launch)

d exec-out screencap -p > a.png; sleep 20; d exec-out screencap -p > b.png; cmp a.png b.png  # differ ⇒ Founder holding the phone ⇒ wait
```

Locked or asleep ⇒ stop; never wake/unlock/swipe/pattern. Any frame that is not our app (shade, lock
screen) is deleted. If the screen changes without agent input, the Founder is holding the phone ⇒
all input stops. No profile/settings/data change. Landscape swipes never start at y ≥ 1000.
